# CoffeeDay
Trabalho com intuito de melhorar o software de um site de cafeteria 

Sistema Web para gerenciamento de cafeteria online.

## Integrantes

- Rúben dos Santos Melo responsável pelo PDF e README do projeto
- Bruna Almeida responsável pelo protótipo no figma 
- João Pedro Carneiro responsável pelo código de execução

## Tecnologias

- React
- JavaScript
- HTML5
- CSS3
- Bootstrap
- Node.js
- Express
- MySQL

## Arquitetura

Arquitetura em Camadas + Cliente-Servidor

Projeto baseado em arquitetura Cliente-Servidor e componentização React.

## Funcionalidades

- Cadastro
- Login
- Catálogo de Produtos
- Carrinho
- Pedidos
- Administração

## Melhorias Futuras

API real
Pagamento online
Dashboard administrativo
Integração com delivery


## Responsividade

Compatível com Desktop, Tablet e Smartphone.
